Privacy Policy

Team Office Calendar · Effective date: November 10, 2026

About this app

Team Office Calendar is a personal tool built and used only by Takaharu Suzuki. It runs on a private server in his home and is reachable only over his private network. It is not offered to the public, and no one else can sign in to it.

What Google data the app uses

When connected to Google, the app requests only these permissions:

  • Calendar events (calendar.events): to show, create, change and delete events on the owner's own calendars.
  • Calendar list (calendar.calendarlist.readonly): to see the names and colors of the owner's calendars, so they can be shown or hidden.

The app does not access Gmail, contacts, Drive or any other Google data.

How the data is used

Calendar data is used only to display and edit the owner's schedule inside the app. It is processed on the home server and is not copied anywhere else. The data is:

  • not sold, rented or shared with any third party;
  • not used for advertising, profiling or market research;
  • not used to train any AI or machine-learning model;
  • not read by any person other than the owner.

How the data is stored

Event data is kept only briefly in the server's memory to draw the calendar. The OAuth tokens that let the app talk to Google are stored on the home server in a private file that only the owner's account can read. They are never published, sent to other services, or included in source code.

How to disconnect

Access can be removed at any time in either of these ways:

  • In your Google Account, open Third-party apps & services, choose Team Office Calendar, and remove its access.
  • On the server, run the app's revoke command. It asks Google to cancel the token and deletes the stored token file.

Google API Services User Data Policy

Team Office Calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
