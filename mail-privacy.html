Privacy Policy

Team Office Mail · Effective date: November 11, 2026

About this app

Team Office Mail is a personal tool built and used only by Takaharu Suzuki. It runs on a private server in his home and is reachable only over his private network. It is not offered to the public, and no one else can sign in to it. It reads and manages only the owner's own Gmail account.

What Google data the app uses

The app is connected in stages. At each stage it requests only the permissions listed for that stage:

  • Read email (gmail.readonly, first stage): to list the owner's messages and show a message's text when the owner opens it.
  • Organize email (gmail.modify, later stage): to archive, mark as read or unread, add or remove the owner's own labels, move a conversation to the trash and restore it from the trash. This permission cannot permanently delete email, and the app never requests the permission that can (https://mail.google.com/).
  • Basic mail settings (gmail.settings.basic, later stage): to create a filter that blocks a sender the owner chose, and to remove only the filters that the app itself created.
  • Send email (gmail.send, last stage): to send a reply, a forward or a new message that the owner has written or reviewed, and to send an unsubscribe request by email when a mailing list asks for one.

The app does not access contacts, Drive, Calendar or any other Google data.

How the data is used

Email data is used only to show the owner his own mailbox and to carry out actions that the owner approves by pressing a button in the app. Nothing is sent, deleted or changed without the owner's approval. The data is:

  • not sold, rented or shared with any third party;
  • not used for advertising, profiling or market research;
  • not used to train any AI or machine-learning model, and not sent to any AI service;
  • not read by any person other than the owner.

When the owner approves an unsubscribe for a mailing list that supports one-click unsubscribe, the app sends the standard one-click request to that mailing list's own unsubscribe address. No email content is included in that request.

How the data is stored

Message content is kept only in the server's memory while it is being shown, and is not written to disk. The app keeps a short activity log on the home server (time, type of action, number of messages, the other party's domain and the result). The log does not contain subjects, message text, email addresses or message IDs. The OAuth tokens that let the app talk to Google are stored on the home server in a private file that only a dedicated system account can read. They are never published, sent to other services, or included in source code.

How to disconnect

Access can be removed at any time in either of these ways:

  • In your Google Account, open Third-party apps & services, choose Team Office Mail, and remove its access.
  • On the server, run the app's revoke command. It asks Google to cancel the token and deletes the stored token file.

Google API Services User Data Policy

Team Office Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
